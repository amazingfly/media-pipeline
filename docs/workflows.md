# Workflow support index

`workflows.json` is the machine-checked source for this index. Supported means
maintained entry point with CPU checks, not a claim of current GPU availability
or deployment. Archived source stays in place to preserve historical paths.

| Workflow | Status | Requirements |
| --- | --- | --- |
| `coordinator` | supported | Component environments |
| `workspace` | supported | One local workspace JSON |
| `provenance` | supported | Existing component manifests |
| `publishing` | supported | Optional publishing dependencies and explicit invocation |
| `littlequeen-legacy` | archived | Historical production recipe; prefer configured coordinator |
